# Qualification Workspace

This directory is reserved for future P5-A1/P5-A2 qualification rulebook, schema, and evidence-review outputs.

P5-A0 does not download data, process data, parse CityGML, run GIS routing, or create generated qualification outputs.

Do not commit raw official datasets, downloaded archives, cache files, temporary GIS exports, or large generated spatial files here.

Future outputs should be validated, documented, and Unity-ready before any Unity integration milestone consumes them.
