# NewMap UI Localization Check

Runtime UI is created by `NewMapRuntimeUI`.

Implemented:

- Start Menu.
- English/Japanese language switch.
- Rules panel.
- Tourism Mode and Evacuation Mode buttons.
- Weather selection buttons.
- Pause menu via `Esc`.
- Language switch from pause.
- Rules from pause.
- Quit to Menu.
- Force Quit button with explanation.
- HUD text for mode, stage, weather, speed, stamina, NPC count, and diagnostics.
- Result panel for success/failure reason codes.

Text uses wrap and best-fit settings to reduce overflow risk.

Final status: `completed_with_documented_runtime_proxy`.
