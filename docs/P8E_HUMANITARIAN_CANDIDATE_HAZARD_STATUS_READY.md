# P8-E Humanitarian Candidate Hazard Status Ready

Humanitarian candidates are ready to participate in P8-C/P8-D hazard-status data flow as non-official proxy objects.

Supported status readiness:

- `hazardStatusEligible=true`
- `p8dDamageStatusEligible=true`
- `p8ePersistentVisibilityReady=true` where coordinates are present
- `p9LifeFirstSelectableReviewNeeded=true`
- `isOfficialShelter=false`

P8-D damage/blockage/collapse visual statuses remain proxy/status only. They are not real engineering assessments and do not change gameplay success/failure rules.

P9 may use these records to decide final life-first vertical evacuation target behavior, but only through entrance / safe-floor / evacuation-complete proxy and explicit non-official labeling.
