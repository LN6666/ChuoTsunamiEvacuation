# Install And Run

## Portable Install

Copy the entire folder:

`ChuoTsunamiEvacuation_v1.0`

to the target Windows computer.

Do not copy only `ChuoTsunamiEvacuation.exe`. The EXE must remain next to:

`ChuoTsunamiEvacuation_Data`

## Run

Double-click:

`ChuoTsunamiEvacuation.exe`

If Windows SmartScreen appears, choose **More info** and **Run anyway** only if this is your own trusted build.

## First Launch Check

1. Launch the EXE.
2. Confirm the start menu appears.
3. Switch language.
4. Open the rules screen.
5. Start Tourism Mode.
6. Start Evacuation Mode.
7. Test movement, sprint, stamina, and mouse drag camera.
8. Use `E` near an interaction target.
9. Use `R` for ranking/leaderboard if available.
10. Check official and non-official target wording.
11. Review `Player.log` if anything fails.
