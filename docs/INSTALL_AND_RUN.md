# Install And Run

## Portable Install

Copy the entire folder:

`ChuoTsunamiEvacuation_v1.0`

to the target Windows computer.

Do not copy only `ChuoTsunamiEvacuation.exe`. The EXE must remain next to:

`ChuoTsunamiEvacuation_Data`

## Run

Double-click:

`ChuoTsunamiEvacuation.exe`

If Windows SmartScreen appears, choose **More info** and **Run anyway** only if this is your own trusted build.

## Fullscreen / Windowed Mode

The Windows build starts in borderless fullscreen by default.

- Press `F11` to toggle borderless fullscreen and windowed mode.
- Press `Alt+Enter` to toggle borderless fullscreen and windowed mode.
- The selected mode is saved locally for the next launch.
- Windowed mode is resizable.

If fullscreen displays incorrectly, press `F11`. If the screen is unusable, create a shortcut to `ChuoTsunamiEvacuation.exe` and add this to the shortcut target:

`-screen-fullscreen 0 -screen-width 1280 -screen-height 720`

Launch from that shortcut, then press `F11` after the start menu appears if you want to return to fullscreen.

## First Launch Check

1. Launch the EXE.
2. Confirm the start menu appears.
3. Switch language.
4. Open the rules screen.
5. Start Tourism Mode.
6. Start Evacuation Mode.
7. Test movement, sprint, stamina, and mouse drag camera.
8. Use `E` near an interaction target.
9. Use `R` for ranking/leaderboard if available.
10. Press `F11` to confirm fullscreen/windowed toggle.
11. Press `Alt+Enter` to confirm fullscreen/windowed toggle.
12. Check official and non-official target wording.
13. Review `Player.log` if anything fails.
