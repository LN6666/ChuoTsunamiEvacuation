# NewMap Name Normalization Rules

- Prefer `name:ja`, then `name`, `official_name`, and only then clearly valid `short_name`.
- Keep only the main Japanese/Kanji display name.
- Hide full postal addresses, coordinate strings, GML IDs, and `bldg_`/`13102-bldg-` IDs in normal mode.
- Do not machine translate and do not fabricate names.
- Visible bad-label counts: ID `0`, address `0`, low-confidence `0`.
