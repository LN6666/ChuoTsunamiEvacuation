# Attribution

This prototype uses or references open/public geospatial source families during preprocessing and Unity map preparation.

## PLATEAU

3D city model source: Project PLATEAU, Ministry of Land, Infrastructure, Transport and Tourism of Japan.

The local PLATEAU source data is not committed to this repository. The final Unity player contains a built local scene prepared from the local PLATEAU import workflow.

## OpenStreetMap

Where OpenStreetMap-derived route, name, or reference data appears in preprocessing outputs, it is attributed to OpenStreetMap contributors and is subject to the Open Database License.

OpenStreetMap data in this project is used for prototype/informational guidance only. It is not official evacuation route certification.

## Japanese Open Data Sources

Where GSI, Tokyo, Chuo City, or other public/open Japanese datasets appear in preprocessing outputs, they are used as project-local references for prototype shelter/target metadata.

## Scope Notice

This game does not provide official disaster guidance. Always follow current instructions from local authorities and official emergency services.
