# Game Rules JA

現在の最終マップは `Chuo_BaseMap` です。

観光モードは探索用です。津波警報、ライトカーテン、危険判定、群衆失敗、倒壊・瓦礫失敗、スタミナ消費は無効です。観光モードのスプリント速度は `10.0 m/s` のままです。

避難モードの最大スタミナは `3500` です。避難モードのスプリント速度は前回の P10 ビルドから 20% 低下し、`4.59 m/s` です。

避難モードは 2 段階の津波モデルを使います。Stage 1 Warning では警報情報を表示し、ライトカーテンは非表示で、リスク接触は失敗判定に使いません。Stage 2 FrontApproaching ではライトカーテンを表示し、危険判定が有効になります。

緑色のフレームは試作ガイダンス用の表示です。公式な承認や安全認定を意味しません。

非公式候補は警告付きで表示されます。非公式候補は公式避難所ではなく、安全承認済みとして扱いません。

ルート表示は推定された試作ガイダンスです。公式避難ルートではありません。

新しいマップ範囲で確認できないターゲットは無効化され、通常のゲームプレイ対象として表示してはいけません。
# ゲームルール

地震と津波警報のあと、東京都中央区で避難します。

## 目的

津波リスク前線が到達する前に、利用可能な避難関連の建物へ到達してください。

## 重要な表示

公式避難所は、データ上で公式避難先として扱える建物です。

非公式の人道的な高層建物候補は、命を守るための垂直避難候補です。公式避難所ではなく、安全または承認済みとはみなしません。公式避難所へのアクセスが危険または不可能な場合のみ使用してください。

津波開始後、緑色の地面フレームが表示されます。これは避難関連の建物範囲または候補範囲を示すもので、公式承認を意味しません。

## ルート

ルート案内は推定プロトタイプ案内です。公式避難経路ではなく、道路ジオメトリとして完全検証済みでもありません。

## ハザードと結果

津波は実際の流体シミュレーションではなく、リスク前線として表現します。混雑、入口閉塞、安全階プロキシ、天候、スタミナ、倒壊・落下物の曝露イベントプロキシが成功または失敗に影響する場合があります。

垂直避難は入口と安全階のプロキシで処理します。実際の屋内シーン、階段、BIM/LOD4 の屋内避難は実装していません。

## 移動

歩行速度は約 0.5 m/s を目標に設定できます。Shift を押すと約 2.5 m/s のスプリントを試みます。スプリントはスタミナを消費します。スタミナが尽きると一定時間スプリントできなくなり、その後段階的に回復します。

雨と夜のモードでは移動速度が低下します。夜モードでは画面が暗くなります。
