# Game Rules JA

現在の基準マップは新しい `Chuo_BaseMap` です。

観光モードは探索用です。津波警報、ライトカーテン、危険判定、群衆失敗、倒壊・瓦礫失敗、スタミナ消費は無効です。

避難モードは二段階の津波モデルを使います。第1段階 Warning では警報情報を表示し、ライトカーテンは非表示で、リスク接触は無視されます。第2段階 FrontApproaching ではライトカーテンが表示され、危険判定が有効になります。

緑フレームは試作ガイダンス表示です。公式な安全承認を意味しません。

非公式候補には警告が必要で、標準では安全承認されません。

ルートは推定プロトタイプ案内であり、公式避難ルートではありません。

新マップに存在確認できないターゲットは無効化され、ゲーム中に表示してはいけません。
