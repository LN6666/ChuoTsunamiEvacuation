# P6-A Navigation Guidance Prototype

Date: 2026-05-21

Branch: `p6a-navigation-guidance-prototype`

## Purpose

P6-A adds a conservative player-facing navigation guidance prototype for evacuation target awareness.

This is display-only support. It is not official navigation, not official evacuation guidance, not live routing, and not a gameplay success/failure rule.

## Implemented Components

Scripts are contained under `Assets/Scripts/Navigation/`:

- `NavigationTargetInfo`: read-only target metadata container. It can be built from a plain `Transform` or from an existing `BuildingShelter` plus optional `RealQualifiedShelterMetadata` / `HumanitarianCandidateMetadata`.
- `NavigationGuidanceCalculator`: pure calculation and text-formatting logic for horizontal direction, Unity world-space distance, estimated time, missing-target fallback, and warnings.
- `NavigationGuidanceResult`: result DTO used by controllers and tests.
- `NavigationGuidanceController`: thin `MonoBehaviour` wrapper that reads a configured player transform and target, then sends display-only results to a view.
- `NavigationGuidanceDisplay`: thin Unity UI wrapper for target text, distance text, estimated time text, status/warning text, and a direction arrow `RectTransform`.

## Safety Boundaries

P6-A preserves inherited P5/P6 boundaries:

- No `sourceMode` change. Default `test` behavior remains owned by existing source config files.
- `real_qualified` remains opt-in.
- Humanitarian candidate flags remain default-off and are not modified.
- No change to `EvacuationGameManager`, `ResultPanelController`, `BuildingShelter`, `ShelterSourceConfigLoader`, or `Assets/Data/shelter_source_config.json`.
- No `ProjectSettings`, `Packages`, Unity scene, `Chuo_BaseMap.unity`, PLATEAU import, or raw PLATEAU data modification.
- No runtime reads from `data_pipeline/raw/download/cache/tmp/.venv`.
- No web requests, live routing, flood simulation, NavMesh adoption, A* dependency, Recast dependency, or package import.
- Navigation feedback remains display-only. `NavigationGuidanceController.AffectsGameplayRules` is `false`.

## Not Official Navigation

The guidance UI reports direction and distance to a selected/active prototype target. It does not validate roads, entrances, legal access, post-earthquake conditions, or official evacuation routes.

Required warning text is generated by `NavigationGuidanceCalculator`:

- `Estimated prototype route`
- `Not official navigation`
- `Not official evacuation guidance`
- `estimated prototype route, not an official evacuation route`
- `Route line rendering disabled until coordinate transform is validated`

When OSM-derived attribution is available from existing metadata, the UI preserves it as `OSM/ODbL attribution`.

## Route Rendering And Live Routing Scope

P6-A does not render real WGS84 route geometry.

Existing P5 route QA found that current route geometry is `EPSG:4326` and no verified WGS84-to-Unity/PLATEAU transform exists. Until a dedicated transform validation milestone approves rendering, route lines remain fail-closed and only distance/time metadata may be shown as feedback.

P6-A also does not call routing services or perform runtime network access. Any route distance or estimated time comes from existing metadata when present; otherwise the prototype uses Unity world-space distance divided by a configurable walking speed.
