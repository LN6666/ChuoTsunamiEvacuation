# P8-A Known Limitations

## P7 Baseline Limitations Carried Forward

- Actual imported LOD coverage is LOD0-LOD2.
- Average LOD3 is not achieved.
- Some expected PLATEAU categories are missing, partial, flat, attribute-only, or not converted into renderable scene objects.

These are accepted practical baseline limitations, not P8 start blockers.

## P8-A Limitations

- Hazard data is sample/manual/test only.
- No official hazard values are claimed.
- Dynamic risk-front visualization is not implemented until P8-B.
- Road/building/bridge/underground hazard interaction is not implemented until P8-C.
- Lightweight collapse proxy behavior is not implemented until P8-D.
- Windows EXE profiling remains a later release-readiness requirement.
