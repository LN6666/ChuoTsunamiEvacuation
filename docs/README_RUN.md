# README_RUN

This folder contains the final portable Windows build of `ChuoTsunamiEvacuation`.

Run:

1. Keep `ChuoTsunamiEvacuation.exe` and `ChuoTsunamiEvacuation_Data` in the same folder.
2. Double-click `ChuoTsunamiEvacuation.exe`.
3. Start with Tourism Mode to confirm the map, camera, labels, and controls.
4. Then test Evacuation Mode.

Do not copy only the EXE. Copy the entire `ChuoTsunamiEvacuation_v1.0` folder.

This is an educational serious-game prototype. It is not for real emergency use.
