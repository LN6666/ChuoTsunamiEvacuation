# Controls

- `WASD` or arrow keys: move
- `Shift`: sprint
- Left mouse drag: rotate camera
- Right mouse drag: rotate camera
- `E`: interact with nearby target/building
- `R`: ranking/leaderboard view if enabled in the current UI
- UI buttons: switch language, open rules, choose Tourism Mode or Evacuation Mode

Tourism Mode has no stamina restriction. Evacuation Mode uses stamina and sprint tuning from the final P10 configuration.
