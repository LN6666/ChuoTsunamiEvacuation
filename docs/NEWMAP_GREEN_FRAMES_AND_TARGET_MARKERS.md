# NewMap Green Frames And Target Markers

Green frame output:

`Assets/Data/P10/newmap_green_frame_targets.json`

Active green frames are attached only to local runtime training proxies:

- `newmap_proxy_safe_floor`
- `newmap_proxy_blocked_entrance`
- `newmap_proxy_no_safe_floor`

All are non-official. `nonOfficialWarningRequired=true` and `safeApprovedByDefault=false`.

No disabled old-map target receives a marker, entrance trigger, route line, or green frame.
