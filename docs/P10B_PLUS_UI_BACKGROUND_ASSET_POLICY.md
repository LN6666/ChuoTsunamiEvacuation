# P10-B+ UI Background Asset Policy

P10-B+ does not commit internet images.

The UI config supports background image opacity around `0.35`, but `backgroundImagePath` is empty by default and the mode is:

`placeholder_until_licensed_asset_confirmed`

Before replacing the placeholder with a Chuo cityscape or aerial image, document:

- source URL
- license
- author or provider
- usage permission

Preferred safe assets:

- project-generated screenshot from the local high-detail scene
- generated project-owned bitmap with clear provenance
- openly licensed image with documented attribution

Do not scrape or download copyrighted assets automatically.
