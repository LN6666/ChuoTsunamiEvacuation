# P8-A Evidence Source Plan

## Current Data Status

P8-A uses sample, synthetic, or manual placeholder hazard data only.

No official tsunami arrival time, inundation depth, water level, tsunami height, hazard intensity, or inundation boundary value is claimed in P8-A.

## Later Evidence Requirement

P8-B through P8-D must review official or academic sources before presenting hazard values as evidence-backed. Required fields include:

- Arrival time.
- Inundation depth.
- Water level.
- Tsunami height where available.
- Inundation boundary.
- Hazard intensity.
- Confidence.
- Evidence source identifier.

## Source Modes

- `test`: test-only data for validation.
- `manual_sample`: manual placeholder data for development.
- `evidence_planned`: schema-ready data that still needs source review.

Unknown source modes must fail safe.
