# P10-B Stress Test Scenarios

Stress scenarios are defined in `Assets/Data/P10/p10b_stress_scenarios.json`.

Required bounded scenarios:

- baseline low marker count
- all official/non-official candidate markers visible
- green ground frames enabled after tsunami start
- bounded high crowd/congestion
- light curtain enabled with green frames
- ResultPanel long warning text
- collapse/debris enabled deterministic proxy
- debug labels disabled performance run
- Low / Medium / High quality-style config

P10-B does not spawn thousands of NPCs and does not introduce a new crowd engine.
