# Release Notes

## ChuoTsunamiEvacuation v1.0

Final PBL11 portable Windows package.

Included:

- Final `Chuo_BaseMap` Windows x64 player.
- Tourism Mode and Evacuation Mode.
- Verified official shelters where available.
- Non-official high-rise candidates with warning semantics preserved.
- Estimated prototype route/ranking guidance.
- Two-stage tsunami warning/front behavior.
- Final stamina tuning: Evacuation max stamina `3500`.
- Final sprint tuning: Evacuation sprint `4.59 m/s`.
- Tourism Mode no-stamina behavior preserved.
- 180-second tsunami warning duration.
- 2270-meter invisible circular playable boundary.
- Mouse left/right drag camera control.
- Player, NPC, spawn, ground, collision, labels, and target-boundary tuning from P2-P10.
- Second-PC install/test guide and report template.

Not included:

- Final release source does not include raw PLATEAU data.
- Git source commit does not include the built EXE, player data folder, or release ZIP.
- No official evacuation route certification.
- No GIS-grade terrain or route validation claim.
