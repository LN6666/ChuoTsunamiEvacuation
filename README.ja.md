# Chuo Tsunami Evacuation

[English](README.md) · **日本語**

**中央大学オープンキャンパス2026の研究室見学に向けて制作した、津波避難ミニゲームです。**

Unityで再現した東京都中央区の3D都市空間を歩き、避難先を比較しながら、限られた時間で避難を試みます。避難先の選択、都市のリスク表示、混雑による遅れについて、来訪者が操作を通して考えられる研究・教育用デモです。

## 制作目的

中央大学オープンキャンパス2026での研究室紹介と、都市の災害避難研究を一般の方に伝えるために制作しました。街を探索し、避難先を選び、時間や入口の利用可否、混雑が結果にどう影響するかを体験できます。

短時間で操作・比較できるよう、現実の災害や避難行動は簡略化しています。ゲーム内で避難に成功しても、その建物や経路が実際の災害時に安全であることを示すものではありません。

## ゲームの概要

| モード | 内容 |
|---|---|
| **観光モード（Tourism Mode）** | 地図を探索し、対象建物を確認できます。スタミナ消費と避難時の危険による失敗判定は無効です。 |
| **避難モード（Evacuation Mode）** | 警報後に利用可能な避難先を選び、リスク前線による失敗判定が発生する前に、安全階への移動処理を完了します。走るとスタミナを消費し、混雑によって時間がかかる場合があります。 |

避難モードは「警報」と「リスク前線の接近」の2段階で進行します。ライトカーテンの表示と危険への接触判定は、第2段階で有効になります。避難先の利用可否、入口の状態、安全階に到達するまでの所要時間が結果に影響します。

雨天・夜間の設定では移動速度が低下する場合があり、夜間は画面が暗くなります。既存の[英語ルール](docs/GAME_RULES_EN.md)と[日本語ルール](docs/GAME_RULES_JA.md)も参照できます。以下では、初めて遊ぶ方向けに主な仕組みを説明します。

![建物名、公式・非公式の区分、利用可否、直線距離を表示した避難先ランキング。](docs/images/shelter-ranking.png)

***Rキー**で避難先ランキングを表示・非表示にできます。距離は直線距離の目安であり、検証済みの徒歩経路や所要時間ではありません。この画像はプレイ中の画面で、結果画面ではありません。*

## ゲームルール

### 基本目標

利用できる避難先に到達し、シナリオの失敗条件が発生する前に、安全階への移動処理を完了してください。建物に近づいたり、緑の枠が見えたりしただけでは避難完了になりません。入口の利用可否、到達までの時間、混雑、シナリオごとの条件が結果を左右します。

### スタート地点

中央区の地図内に設定された位置から開始します。プレイヤーは街にいる歩行者を想定しています。シナリオによって開始位置が異なる場合がありますが、実際の避難開始地点を推奨するものではありません。

### 避難先の選択

資料に基づく公式避難先の参照情報、非公式の高層建物・人道的避難候補、その他の訓練用対象を区別しています。近づく前に、対象のラベルと利用可否を確認してください。

非公式候補は、公式避難所として扱いません。ゲームに登場していても、一般の立ち入り、建物の適合性、安全性が保証されるわけではありません。緑の枠もゲーム上の案内表示であり、安全認定ではありません。現在の地図で利用できない対象は無効化されています。

### 案内表示

方向を示す線、案内マーカー、避難先ランキングを参考に、周囲とリスク前線を確認しながら移動します。案内は試作上の推定です。直線は建物や障害物を横切る場合があり、そのまま歩ける経路を示しません。最寄りの対象や最短の表示距離も、公式の避難推奨ではありません。

### 津波リスクの表示

ライトカーテンは、時間の切迫と安全に移動できる空間の縮小を伝えるための、簡略化された演出を含むリスク前線です。実際の波高、流速、浸水深、公式の浸水想定を再現していません。警報段階ではカーテンを表示せず、リスクへの接触を失敗判定に使いません。前線接近段階で表示と危険判定が有効になります。

### 危険区域

シナリオ設定によって、場所や建物が危険、閉塞、利用不可として扱われる場合があります。水辺、道路、橋、地下空間のリスクは展示で取り上げる題材ですが、適用される判定は設定に依存します。実測のハザードマップや道路閉鎖予測ではなく、各題材に独立したプレイ用シナリオがあることも保証しません。

### NPCと混雑

街にはNPCが配置され、避難先周辺の混雑によって、安全階への移動に入口での待ち時間が加わる場合があります。その遅れで、到達可能だった避難先への避難が間に合わなくなることもあります。群衆の動きはゲーム用の簡易モデルであり、現実の人流予測ではありません。遠方のNPCは負荷軽減のため簡略化される場合があります。

### 屋内・垂直避難

利用可能な建物の入口付近に移動して、**Eキー**を押してください。入場できる場合、設定された上階への移動時間と混雑による遅れを使って、安全階への移動処理を行います。

**現在のリリースには、自由に歩ける実際の建物内部はありません。** 階段、廊下、上階への移動は抽象化した処理で表現しており、実際の間取りや屋内避難経路の再現ではありません。[屋内シーンに関する決定](docs/P9_NO_INDOOR_SCENE_DECISION.md)を参照してください。

### 成功条件

選んだ対象が利用可能で、失敗条件が発生する前に、安全階への移動処理を完了すると成功です。入口と安全階の利用可否に加え、混雑による待ち時間を含めて間に合うかどうかが重要です。

### 失敗条件

シナリオによっては、リスク前線がプレイヤーや避難先に到達したとき、入口が閉塞しているとき、安全階が利用不可のとき、または設定された危険条件に該当したときに失敗します。混雑による遅れで間に合わなくなる場合もあります。失敗メッセージはゲーム内の条件を説明するもので、実際の災害リスク評価ではありません。

### 結果表示

成功・失敗、選択した避難先、注意事項、失敗理由を表示します。シナリオや評価用の処理によっては、結果画面やローカルの実行記録に、入口到達・上階移動の時刻、推定経路時間、リスク到達時刻、混雑情報なども含まれます。すべての項目が毎回表示されるわけではありません。

## 操作方法

| 操作 | キー・入力 |
|---|---|
| 移動 | **W / A / S / D** または **矢印キー** |
| 走る | **左または右Shift** |
| カメラを回す | **マウスの左または右ボタンを押しながらドラッグ** |
| 近くの建物を調べる・避難先に入る | 入口の操作範囲内で **E** |
| 避難先ランキングの表示切り替え | **R** |
| プレイ中の一時停止・再開 | **Esc** |
| モード・言語の選択、ルールの表示 | 画面のボタンをクリック |
| ボーダーレス全画面・ウィンドウ表示の切り替え | **F11** または **Alt + Enter** |

観光モードにはスタミナ制限がなく、避難モードではスタミナを使用します。表示モードの補足は[操作資料](docs/CONTROLS.md)を参照してください。

## デモの比較例

シナリオ確認や試作条件では、次のような内容を比較します。

- 利用可能な公式避難先の参照対象に間に合うケース。
- 警報段階と、ライトカーテンが接近する段階の違い。
- 設定に応じた経路・危険条件と、道路・橋・地下・水辺に関する検討。
- 入口の混雑による避難時間の変化。
- 建物への入場と、抽象化された安全階への移動。
- 注意表示を伴う、非公式高層建物の「人命優先候補」。

展示・比較用のケースであり、公式の防災計画や、6つの独立した選択メニューを意味しません。[シナリオ状況](docs/NEWMAP_SCENARIO_FINAL_STATUS.md)と[非公式候補のルール](docs/P9C_LIFE_FIRST_VERTICAL_TARGET_RULES.md)に、実装上の範囲を記録しています。

## Windows版

**[P11 Final v1.0 — Windows x64](https://github.com/LN6666/ChuoTsunamiEvacuation/releases/tag/p11-final-v1.0)** をポータブルZIPとして公開しています。圧縮ファイルは約 **2.05 GB** です。

**完成版に残っている問題：** 街の各所に小範囲の見えない当たり判定（いわゆる「見えない壁」）が多数残っており、移動を妨げる場合があります。また、ゲームの容量が想定より大きいため、ダウンロード時間と展開先の空き容量に余裕を持ってください。プロジェクトの完了は、これらの問題が解消済みであることを意味しません。

1. リリースページから `ChuoTsunamiEvacuation_v1.0.zip` をダウンロードします。
2. ZIP全体をローカルフォルダーに展開します。
3. 実行ファイル、`ChuoTsunamiEvacuation_Data/`、同梱のランタイムファイルを同じ場所に保ちます。
4. `ChuoTsunamiEvacuation.exe` を起動します。まず観光モードで地図と操作を確認し、その後に避難モードを試してください。

## 利用上の注意

本作は研究・教育用の試作であり、**公式の防災製品や、実際の避難案内システムではありません。**

- 実際の避難判断には使わず、自治体や緊急対応機関の最新の指示に従ってください。
- 津波や危険の表現は簡略化した仕組みであり、物理的な災害予測ではありません。
- 建物への入場、上階への移動時間、経路、地面、NPCの動きは試作上の表現です。候補建物は公式避難所ではありません。
- 詳細な3D外観があっても、道路、地形、入口、屋内の精度が保証されるわけではありません。名称や見た目の位置合わせに不完全な部分があります。
- 街には小範囲の見えない壁が多数残っており、一部の場所で移動できないことがあります。
- ゲームの容量が大きく、圧縮状態で約2.05 GBあります。ダウンロードと保存には十分な時間・空き容量が必要です。

展示や評価に使用する前に、[既知の制限](docs/KNOWN_LIMITATIONS.md)を確認してください。

## データと出典

都市空間の制作には、国土交通省の **Project PLATEAU** による3D都市モデルを使用しています。データ準備では、記録された出力に応じて、中央区・東京都の公式避難先や適合性に関する資料、OpenStreetMap由来の経路・名称情報、国土地理院などの公開データを参照しています。

OpenStreetMap由来の内容の出典は **OpenStreetMap contributors** で、**Open Database License（ODbL）** の対象です。危険条件、混雑による遅れ、安全階への移動、調整値などには、独自のゲーム用データを使用しています。Unityとパッケージの依存関係は [Packages/manifest.json](Packages/manifest.json) に記載され、それぞれの利用条件が適用されます。第三者の素材を一括して自由利用できることを意味しません。

詳細は[データ出典](docs/DATA_SOURCES.md)、[権利表記](docs/ATTRIBUTION.md)、[建物名称の出典](docs/NEWMAP_NAME_LABEL_ATTRIBUTION.md)を参照してください。ゲーム実行中は準備済みのローカルデータを使用し、オンラインの地図・名称検索サービスには問い合わせません。
